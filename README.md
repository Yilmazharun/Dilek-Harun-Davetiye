# Dilek & Harun — Düğün Davetiyesi 💍

20 Ekim 2026 · Horasan / Erzurum

Tek dosyalık (index.html) dijital düğün davetiyesi. Türkçe ve İngilizce, katılım bildirimi ve fotoğraf gönderimi WhatsApp üzerinden.

## WhatsApp numarasını değiştirme

`index.html` dosyasında şu satırı bulun ve numarayı ülke koduyla, başında `+` veya `0` olmadan yazın:

```js
const WA_NUMBER='905001234567';
```

Örnek: 0532 123 45 67 → `905321234567`

## İngilizce link

Sitenin adresinin sonuna `?lang=en` eklerseniz site İngilizce açılır.
